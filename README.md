# MediTalk

MediTalk is a multilingual telemedicine app that helps patients and clinicians communicate across language barriers through video consultations and translated live captions.

### Highlights
- Speech recognition and live translation with medical glossary support
- Appointment booking and role-based patient, clinician, admin, and interpreter portals
- Interpreter requests and multilingual interface

**Built with:** MongoDB, Express, React, Node.js, Socket.IO, and WebRTC.

> This is a student project. Machine translation is not a substitute for a qualified medical interpreter. Do not use with real patient data.
